# Reti-Logiche
Prova Finale di Reti Logiche (Digital Logic Design final project), Politecnico di Milano, a.y. 2024/2025. Final grade: 30/30 cum Laude.

The Digital Logic Design Final project requires to implement an hardware module, described in VHDL, to apply a differential filter to a byte sequence read from a memory module, writing the result of the computation in the same memory. The module is designed for a FPGA, and it was written and simulated in Vivado. The report includes all design decisions such as architecture (registers, address computation, filter computation modules) and FSM design, as well as experimental results for simulation and synthesis.
